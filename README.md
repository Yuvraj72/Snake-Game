# Snake Game

A classic Snake game built with vanilla JavaScript as a practice project to revise HTML, CSS, and JavaScript fundamentals.

## How to Play

- Use Arrow Keys to control the snake
- Eat the red food to grow and increase your score
- Avoid hitting the walls or yourself
- Try to beat your high score!

## Features

- Smooth gameplay using `requestAnimationFrame`
- High score persistence with localStorage
- Sound effects for actions
- Gradient background with animations
- Responsive grid-based design

## Tech Stack

- HTML5
- CSS3 (Grid Layout, Animations)
- Vanilla JavaScript
